Blocked on one answer

Which asset is correct?

I already guessed once — kaiibi-mark-white.png on a blue plate, reasoning it matched the app icon — and it is still wrong. Candidates: kaiibi-mark-white/black.png (200×212, the bare bag), kaiibi-logo-transparent.png and kaiibi_log.png (200×298, the bag plus the "ka iibi" wordmark), icon.png, splash-icon.png.

If the answer is the full lockup, it already contains the wordmark — so the masthead drops its own Kaiibi text, or the page says the name twice, which is the repetition the masthead was built to remove.

  • !Set both width and height from KAIIBI_MARK_ASPECT. An Image with a height and an aspectRatio but no width takes its intrinsic width — that drew the footer's 24px mark 200px wide.
