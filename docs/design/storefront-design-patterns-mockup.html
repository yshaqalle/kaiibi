Storefront · pattern exploration

Four patterns for a more polished storefront

Same system underneath every one — the seven palettes, the WCAG gates, the fixed checkout blue and WhatsApp green, the slip, the 1320px column. What varies is the composition: where the shop's identity sits, how dense the goods are, and what the page leads with. All four are drawn in Azure; every one recolours through the palette like everything else. All four are plain React Native — no library the app doesn't already carry.

A · Refined Bento — polish, not surgery

The shipped composition, kept — anchor, pills, grid — with the finish layer it never got. This is "optimize the design we have" taken literally.

What changes

  • The anchor gets an accent glow — a radial wash of the palette's accent at 16% opacity bleeding from one corner of the ink card. One expo-linear-gradient radial (or a pre-rendered PNG), and the flat slab reads as lit. Recolours per palette automatically because it IS the accent.
  • Status becomes a pill row — "Open until 9pm" (accent-filled when open) beside "Collection". The open state finally lives on the shop page, not just the directory.
  • Tiles float — 6% ink shadow, photo inset to radius 13 with 6px of card visible around it. Borderless stays; depth arrives.
  • Price row carries the stock word — price left, "In stock"/"Ask us" microtext right, so the tile answers both questions on one line.
  • Category pills show counts — "Shirts · 3". Cheap, and the page stops feeling like a guess.
  • Search gets its glyph and a 12-radius field instead of the bare bordered box.

  • The decision card leads — open state, then the landmark in serif at direction-card size, then the two actions that matter: Get directions (mapsUrlFor() already exists) and WhatsApp. On `ink`, so it is the page's one dark card — screenshot it and any driver in Hargeisa can read it.

  • Delivery areas become priced chips — scannable in one glance, phrased as the alternative: "if you'd rather stay put."
  • Contact flattens to an icon row — Call · Instagram · Share shop, the new affordance: a customer forwarding the shop to a friend is the cheapest marketing kaiibi can give a merchant.

One honest gap: the decision card wants a landmark line and today the row carries address/neighborhood/city. If collectAddress is written landmark-style (this region mostly does), it slots in as-is; a dedicated optional "near…" field in the editor is the clean version.

Wave 2 — ideas aimed at the customer's trust

Beyond composition: the things that make a stranger like a shop enough to walk over or order. Ranked by expected effect.

  • Somali-first storefront. The single biggest lever on this list. The customer reading a forwarded link in Hargeisa reads Somali; every storefront string is English today. A ~40-string table (so/en), shop picks its language in the editor, customer can flip. The landing page already ships a language switch, so the precedent exists in-repo. Needs product sign-off + a native speaker's review — not a task yet.
  • The trust strip on the Shop tab. One quiet line under the anchor — "Open until 9pm · Collect near Deero Mall · Pay on collection" — so a customer never needs the Visit tab to feel safe ordering. Composes from data already on the page.
  • Share, everywhere it pays. "Share shop" on Visit (above) and "Share" on the product sheet — both via the existing waLink composer, with the product's name and price in the prefilled message. Customers forwarding products IS the storefront's growth loop.
  • Sold-out that answers. "Ask us" today is a label plus a generic WhatsApp button. Ensure the tap composes "Is the Denim Jacket coming back?" — the product's name in the message — so the shop's reply can be a sale.
  • The order link that reassures. The confirmation already gives a saved status link; have the status page show the fulfilment word and the shop's open state alongside the order — the customer's "is it ready yet?" answered without a chat message.

The polish kit — applies under any pattern

Cross-cutting finish that costs little and is most of what "modern" actually reads as. Half of it already exists in the codebase and just isn't applied everywhere.

  • Press feedback everywhere pressable — press-feedback.ts ships a scale/ opacity treatment; tiles and category pills don't use it yet. Every touch should answer.
  • Image fade-in + skeleton — storefront-skeleton.tsx exists for load; give tile photos a 150ms opacity fade on load so the grid stops popping.
  • The soft gradient photo fallback — a no-photo tile today is flat soft; a 150° two-stop gradient of soft→slightly-deeper (drawn from the palette) reads as intentional rather than missing. Used in every specimen above.
  • Tabular numerals on every price — TABULAR exists; audit the slip, rails and steppers so digits never wiggle.
  • Focus rings on web — the storefront is a website for its customers; outline: 2px accent on focus-visible for pills, tiles, slip.
  • Reduced motion respected — the glow, fades and stepper morph all no-op under prefers-reduced-motion / RN's isReduceMotionEnabled.

Motion — and the React Bits question

reactbits.dev was offered as a resource. Verified against its own docs: ~165 components, React DOM only (JS/TS × CSS/Tailwind, installed via shadcn/jsrepo; official ports for Vue and Svelte, none for React Native).

Its components cannot mount here. The storefront is one React Native codebase rendering to the native app and the web page through react-native-web — a DOM component library has nowhere to attach. And the page's own performance thesis cuts the same way: scale.ts declined even a webfont because this page arrives as a forwarded WhatsApp link on the slowest connection in the flow. A WebGL aurora fails that test before it fails the technical one.

What React Bits is good for here: a pattern catalogue. The ideas port; the code doesn't. The few that serve this page, translated to Reanimated (already in the Expo stack, runs native + web):

React Bits ideaVerdictAs built here
CountUpAdoptThe slip's total ticks to its new value on add/remove — 200ms, tabular numerals so nothing shifts. The one place live motion carries information.
BlurText / SplitText revealAdopt, onceThe anchor wordmark and status pills stagger in on first load only — opacity + 8px translateY, 250ms, never on tab switches.
SpotlightCard / hover liftAdopt on webTiles lift 2px with a deeper shadow on hover (web only); pairs with the existing press-feedback scale on touch.
Aurora / Particles / Waves backgroundsDeclineWebGL against a 3G-first page, decoration on a merchant's surface. The pattern-A accent glow is the calm version of the same instinct.
Cursor effects, Magnet, Dock, tilt cardsDeclineTouch-first customers have no cursor; a tilting product card is a gimmick between a person and a price.

Three rules govern all of it: motion runs once (on load or on change, never looping), stays fast (150–250ms), and no-ops under reduced motion on every platform. If the flashier React Bits pieces are wanted anywhere, that conversation is about a separate marketing site, not this codebase — even kaiibi's landing components here are React Native.
